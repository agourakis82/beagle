# Eval #1 — Residual confabulation rate of the P1 structural redactor

Reproducible experiment for the CPP2026 line of work on neurosymbolic verification
of LLM-generated scientific text. It answers one of the open questions left by the
deep-research synthesis: **after structural verdict-binding (P1), what residual rate
of fabricated solver attributions survives into the reviewer's output?**

## Background

The Triad's adversarial reviewer (ARGOS) is given *verified* formal-solver findings
to cite. A live run exposed a confabulation failure: the reviewer attributed a
`theorem.prove` verdict (`UNKNOWN`) to a solver call that never ran. The structural
fix (P1) records every solver invocation in a `VerdictRegistry` and a post-hoc
validator (`VerdictRegistry::redact_unattested`) redacts any sentence that attributes
a verdict to a verb with no matching *attested* record. This eval measures whether
that redactor actually works.

## What is measured

The redactor's **recall and precision** against a labeled adversarial corpus, with
ground-truth labels fixed **by construction** (one failure class per label), so the
labels carry no annotator noise.

- **recall** = fabricated attributions caught / all fabrications
- **residual confabulation rate** = `1 − recall` (fabrications that survive)
- **precision** = caught / all redactions
- **false-positive rate** = legitimate lines wrongly redacted / all legitimate lines

Scope (honest): the *end-to-end* residual rate is `P(ARGOS confabulates) × (1 − recall)`.
This harness measures the `(1 − recall)` factor rigorously and deterministically. The
live `P(confabulate)` factor requires running the real reviewer under a
confabulation-inducing condition and is the **layer-2 follow-up** (not in this harness).

## Corpus

`corpus.jsonl` — 84 single-line cases (12 per class, ~50/50 PT/EN), generated by a
model fan-out where each agent produced realistic ARGOS-style prose for one assigned
failure class. The class fixes the label; the agent only varies the surface text and
the accompanying `VerdictRegistry` state.

| class | label (should redact?) | what it tests |
|---|---|---|
| `attested_legit` | no | verb + verdict backed by a real matching record |
| `fabricated_no_record` | yes | verb + verdict, no record (the live bug) |
| `fabricated_gate_off` | yes | record exists but `gate-off` (solver never ran) |
| `fabricated_abstain` | yes | record is an abstain marker (no verdict produced) |
| `benign_bait` | no | tricky substrings ("satisfatório", "datasets") / abstract verb mention, no attribution |
| `multiverb_mixed` | yes | two verbs on one line, one attested + one not |
| `multiverb_all_attested` | no | two verbs on one line, both attested |

Each line: `{category, expected_redacted, lang, text, records:[{verb,result}], rationale}`.

## Run

```bash
cargo run -p beagle-triad --bin eval_confabulation
# optional: cargo run -p beagle-triad --bin eval_confabulation -- <corpus.jsonl> <out_dir>
```

Writes `results.json` (machine-readable: metrics + per-class confusion + per-case) and
`results.md` (paper-ready tables). Deterministic — no network, no LLM at eval time.

## Result (and what the eval found)

The first run measured **recall 0.833 / residual confabulation 0.167**: all 8 misses
were fabricated `gum.propagate` attributions citing `gum-understated`/`gum-ok`. Root
cause — a **real deployed gap**: the redactor's verdict vocabulary omitted the GUM
tokens, so GUM fabrications were invisible to it. A second issue: one benign line
discussing the *concept* "d-separation" near `causal.dsep` was over-redacted because
the detector used the broad `d-separ` prefix.

Both were fixed in the redactor (add GUM verdict tokens; key d-sep detection on the
verdict words `d-separated`/`d-connected`, not the concept). After the fix:

| metric | before | after |
|---|---|---|
| recall | 0.833 | **1.000** |
| residual confabulation rate | 0.167 | **0.000** |
| precision | 0.976 | **1.000** |
| false-positive rate | 0.028 | **0.000** |
| F1 | 0.899 | **1.000** |

Regression tests lock both fixes (`test_redact_unattested_flags_fabricated_gum_verdict`,
`test_redact_unattested_no_false_positive_on_dseparation_concept`).

## Caveats for the writeup

- Detection keys on **canonical verdict tokens** (the exact result strings the verbs
  emit). A reviewer that paraphrases a verdict without the canonical token (e.g. "the
  uncertainty was understated" instead of `gum-understated`) is out of scope for this
  layer; the corpus uses canonical forms, matching how findings are injected.
- The corpus is synthetic-by-construction (reliable labels, controlled coverage), not
  sampled from live runs. The layer-2 follow-up should sample real ARGOS outputs.
- `0.000` residual on this corpus means the redactor covers the enumerated failure
  classes, not that confabulation is impossible — only that it is structurally caught
  on every pattern we constructed.
