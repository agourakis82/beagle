# Beagle Exocortex Connector Privacy Policy

Last updated: 2026-04-26

Beagle Exocortex is a personal MCP connector operated for the Beagle exocortex system. It lets authenticated AI clients read and, when explicitly scoped, write to the user's Beagle memory and research state.

## Data Processed

Beagle may process:

- Search queries and tool arguments sent by connected AI clients.
- Memory snippets, project summaries, Chronoself state, audit events, and trust metadata returned from the Beagle cluster.
- Imported conversations when the user or an authorized agent explicitly calls an import/write tool.
- Optional Apple-device context such as sleep, activity, energy, and watch-derived signals if the user has synced those signals to Beagle.

## Purpose

Data is used to provide personal memory search, exocortex continuity, project context, research support, auditability, and agent orchestration.

## Data Sharing

Beagle does not sell personal data. Data returned through the connector is shared only with the authenticated MCP client that the user connects, such as Claude or ChatGPT. Those clients may process data under their own terms and privacy policies.

## Health Context

Health and body data is used only as personal context for productivity, reflection, and planning. It is not medical advice, diagnosis, monitoring, or treatment.

## Authentication

The public connector is designed to use OAuth 2.1 bearer tokens with scopes. Legacy bearer tokens may be enabled only for trusted private agents or transitional operations.

## Contact

For privacy or deletion requests, contact the Beagle operator for the `agourakis.com` domain.
