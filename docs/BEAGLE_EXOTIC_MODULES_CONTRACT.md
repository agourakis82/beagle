# BEAGLE Exotic Modules Contract

This document turns the exotic modules from ambient ambition into testable
scientific machinery.

## Scope Correction

PBPK is no longer owned by BEAGLE in this set. PBPK work belongs to Sounio.
BEAGLE may consume Sounio outputs as scientific artifacts, provenance, or model
evidence, but it should not reimplement PBPK here.

The exotic modules are not automatically drift. They are core when they help the
personal scientific exocortex explore, rank, stress, repair, or document unusual
hypotheses under evidence.

## Non-Negotiable Gates

- Every exotic module must have a deterministic local path that works without a
  remote LLM or lab server.
- Every core operation must have tests that assert behavior, not just
  compilation.
- Claims of subjective consciousness, transcendence, or completeness are not
  allowed as product facts. Use measurable terms such as emergence metrics,
  contradiction pressure, novelty, curvature, uncertainty, or confidence.
- "Production" means wired contract, local fallback, test coverage, and a user
  workflow. It does not mean a document saying 100 percent complete.
- UI is useful only when it reduces cognitive load or operates the research
  loop from thought to artifact.

## Module Roles

- `beagle-quantum`: hypothesis superposition, evidence interference, and
  measurement. It is useful when competing hypotheses need to be kept alive
  until evidence changes their weights.
- `beagle-hyperbolic`: semantic hierarchy, curvature, centrality, and anomalous
  links. It is useful when the memory graph needs geometry, not just flat
  cosine ranking.
- `beagle-fractal`: recursive multi-scale compression and propagation. It is
  useful when the same scientific motif appears at note, paper, project, and
  field scale.
- `beagle-void`: uncertainty, negative-space exploration, and reintegration. It
  is useful when the system must surface what is missing, suppressed, or not yet
  expressible.
- `beagle-noetic`: collective evidence and agent resonance metrics. It is
  useful only when it compares independent perspectives with provenance.
- `beagle-ontic`: ontology dissolution and reintegration. It is useful when a
  stale conceptual frame must be deliberately broken and rebuilt.
- `beagle-paradox`: contradiction forcing and consistency repair. It is useful
  when true tensions should be preserved instead of averaged away.
- `beagle-cosmo`: physical-law and scale sanity checks. It is useful when a
  hypothesis needs to be tested against boundary conditions.
- `beagle-transcend` and `beagle-eternity`: orchestration layers only after the
  primitive modules above are proven by tests and workflow use.

## Current Implementation Step

The first real slice is deliberately small:

- `beagle-hyperbolic` now computes Poincare-ball distance instead of an invalid
  acosh expression, and communities are actual connected components.
- `beagle-quantum` now keeps hypothesis sets stable when empty or degenerate.
- `beagle-quantum` interference now works offline with deterministic lexical
  similarity when embeddings are unavailable.

The next slice should connect these primitives to one living BEAGLE workflow:
thought capture -> hypothesis set -> evidence interference -> hyperbolic memory
placement -> adversarial review -> artifact.
