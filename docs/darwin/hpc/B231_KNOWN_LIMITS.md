# B23.1 — Known Limits

- The memory hierarchy is bounded to three storage-oriented buckets and is not a
  full cognitive architecture.
- The graph layer is assembled from the current retrieved support set; it does
  not materialize a global persistent graph.
- Graph hops are intentionally shallow and capped by the request.
- The pilot improves structure and graph-aware recall, but it does not change
  scientific readiness or editorial readiness states elsewhere in Beagle.
