# B20.8 GO / NO-GO

`GO` if:
- the sub-agent list is live and role-tagged
- role-aware routing resolves bounded work modes to the expected inner environment
- tool dock surfaces publish the same recommendation
- restart preserves the same Beagle-owned identity
- cluster stays green
- Slurm stays green

`NO-GO` if:
- routing mints a new workspace/session identity
- tool dock recommendations diverge from route resolution
- restart breaks role metadata or workspace coherence
