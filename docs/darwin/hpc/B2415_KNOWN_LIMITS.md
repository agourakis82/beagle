# B24.15 Known Limits

- B24.15 does not apply the manuscript candidate policy globally.
- B24.15 does not move `manuscript` off control by itself.
- B24.15 does not remove human review visibility; approve, edit, and reject remain first-class.
- B24.15 can stage or roll back manuscript shadow independently, but it does not supersede the existing implementation or analysis canary rollback paths.
- B24.15 records bounded manuscript sample accumulation on the current workstream identity only; it does not create a second control plane.
