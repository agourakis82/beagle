# B13.5 Known Limits

## Current limits

- the promoted scope is broader than `small-medium`, but it is still bounded to
  Darwin/HPC/Beagle internal non-infra development
- the phase remains pinned to one canonical repo and one active workspace-plane
  branch at a time
- VM still exists as fallback support; this phase only proves that it stays
  fallback-only in the larger scope
- the live proof still uses one canonical operator path and one canonical
  workflow at a time
- no new ingress, HA, topology, provider expansion or cluster-base-infra work
  is introduced here
- this phase does not reopen B9, B10, B11 or B12

## Interpretation

B13.5 is a controlled scope expansion of the default dev plane, not a global
promotion of every possible workflow and not a new infrastructure phase.
