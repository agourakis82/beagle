# B23.2 — Known Limits

- Promotion is heuristic and bounded; this phase does not introduce autonomous
  long-horizon memory rewriting.
- Forgetting is policy-visible, but this phase does not run large background
  compaction jobs or archival migrations.
- GraphRAG query-mode routing is bounded and rule-based; it is not a learned
  planner.
- Editorial and scientific readiness limits remain explicit and unchanged.
