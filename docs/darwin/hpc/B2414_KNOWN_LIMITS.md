# B24.14 Known Limits

- B24.14 does not apply the candidate policy globally.
- B24.14 does not move `manuscript` off control.
- B24.14 does not remove human review visibility; approve, edit, and reject remain first-class.
- B24.14 can hold or roll back manuscript shadow independently, but it does not supersede the existing implementation or analysis canary rollback paths.
- B24.14 records guarded expansion state on the current workstream identity only; it does not create a second control plane.
