# B24.13 Known Limits

- B24.13 does not apply the candidate policy globally.
- B24.13 does not move `manuscript` off control.
- B24.13 does not remove human review visibility; approve, edit, and reject remain first-class.
- B24.13 can roll back analysis independently, but it does not supersede the existing implementation canary rollback path.
- B24.13 records guarded expansion state on the current workstream identity only; it does not create a second control plane.
