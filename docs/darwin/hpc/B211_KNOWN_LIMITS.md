# B21.1 Known Limits

- The manuscript loop is still bounded and operator-triggered; it is not
  autonomous orchestration.
- The manuscript subagent is an inner environment of the same canonical
  workspace, not a separate workspace substrate.
- The loop consumes the current canonical campaign artifacts; it does not create
  a new manuscript automation pipeline beyond the bounded manuscript pack layer.
- Access remains private/internal and inherits the managed attach constraints
  already frozen in `B20.4` and `B20.5`.
