# B21.6 — Known Limits

- The sandbox handshake may legitimately return `auth-blocked` when test
  credentials are absent or rejected; that still proves the live boundary.
- This phase records test-environment receipts only; it does not mint a DOI
  and it does not submit to Crossref production.
- `claim-linked-human-eval-pending` remains a real epistemic blocker for
  scientific maturity and public `findable` release.
- The phase proves technical contact with the registries, not reviewer-ready
  scientific closure.
