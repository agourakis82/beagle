# B20.8 Known Limits

- Routing is bounded and static; it is not autonomous orchestration.
- The selected sub-agent still lives inside the same shared workspace; this phase does not create isolated compute sandboxes per role.
- Attach remains private/internal and inherits the existing managed attach plane from B20.4/B20.5/B20.6/B20.7.
- Tool dock specialization is recommendation-driven; it does not transfer canonical state ownership to any client.
