# Figma ↔ código

São **dois arquivos de design, sem interseção** — e é por isso que este README virou índice.

As duas faixas mantiveram, cada uma, um `figma/README.md` próprio e diferente; ao juntá-las o
conteúdo colidiu inteiro. Concatenar produziria um documento com dois começos e dois assuntos,
e escolher um lado apagaria um sistema de design inteiro. Separados, cada um continua sendo o
documento que era.

| documento | arquivo no Figma | do que trata |
|---|---|---|
| [MISSION_CONTROL.md](MISSION_CONTROL.md) | Beagle Mission Control — Sovereign Dark | o cockpit: frota, lanes, oficina |
| [COMPANION.md](COMPANION.md) | Beagle Companion — sistema e telas | o companion: conversa, presença, corpo |

Fonte de verdade dos tokens, para os dois: `beagle-ios/BeagleSuite/Sources/BeagleCore/Theme.swift`.
